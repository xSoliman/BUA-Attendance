# Distribute QRs — Step-by-Step Guide

Follow these steps every time you want to distribute QR codes to students.

---

## Folder structure

```
DistributeQRs/
├── README.md               ← this file
├── send_qr.py              ← sends emails
├── students.xlsx           ← generated by prepare step (ID, Email, Section)
├── Already Sent            ← keep notes here on what was already sent
├── qrcodes/                ← place QR PNG files here before sending
└── Prepare_sheet/
    ├── prepare_students.py ← generates students.xlsx
    ├── all.csv             ← full student registry (ID number, Email address)
    └── sections.xlsx       ← target students (ID, Name, Section — one or more tabs)
```

---

## Prerequisites

Install dependencies once:

```bash
pip install pandas openpyxl
```

---

## Step 1 — Place the QR codes

Copy the QR PNG files for the target sections into the `qrcodes/` folder.

Each file must be named `<ID>.png` (e.g. `20210001.png`).

You can generate QR codes from the web tool at the Tools page, or use the
`scripts/qr_generator/` script. The files can be flat inside `qrcodes/` or
inside sub-folders — `send_qr.py` looks for `qrcodes/<ID>.png` directly.

> If a student's QR file is missing, that student is skipped and logged.

---

## Step 2 — Update input files (if needed)

| File | When to update |
|------|---------------|
| `Prepare_sheet/all.csv` | When the student registry changes (new students, updated emails) |
| `Prepare_sheet/sections.xlsx` | When the target sections change |

`all.csv` must have these columns: `ID number`, `Email address`

`sections.xlsx` must have these columns per tab: `ID`, `Name`, `Section`
(one tab per group is fine, or everything in one tab)

---

## Step 3 — Prepare students.xlsx

Run from inside `Prepare_sheet/`:

```bash
cd Prepare_sheet
python prepare_students.py
```

The script will:

1. Show all available sections found in `sections.xlsx`
2. Ask which sections to include — type them space-separated, or type `all`

```
Available sections:
  A1
  A2
  B7

Enter section codes separated by spaces, or type "all" to include everything.
Sections: A1 B7
```

3. Match each student ID against `all.csv` to find their email
4. Print a summary and save a full report to `Prepare_sheet/report.txt`
5. Write `students.xlsx` in the `DistributeQRs/` folder

Check `report.txt` before continuing — it lists every matched student (with
email) and every missing student (no email found). Fix any missing entries in
`all.csv` if needed, then re-run.

---

## Step 4 — Send the emails

Run from inside `DistributeQRs/`:

```bash
python send_qr.py
```

You will be prompted for:

```
Enter your name (e.g. Eng. Ahmed): Eng. Ahmed
Enter your email: ahmed@bua.edu.eg
Enter password for ahmed@bua.edu.eg:
```

The password is never stored — it is only used for the current session.

The script connects to `smtp.office365.com` (Microsoft 365 / Outlook).
Each student receives an email with their QR code attached.

Progress is printed live:

```
✅ Sent to student@bua.edu.eg (ID: 20210001)
✅ Sent to student2@bua.edu.eg (ID: 20210002)
⚠️  QR not found for ID 20210099, skipping.
...
Done! ✅ 78 sent, ❌ 2 failed.
```

---

## Step 5 — Record what was sent

Open the `Already Sent` file and note the sections and date:

```
2026-03-23 — Sent to A1, B7 (Logic Design — Eng. Ahmed)
```

This helps avoid sending duplicates in future runs.

---

## Troubleshooting

**"QR not found for ID ..."**
The PNG file for that student is missing from `qrcodes/`. Generate it and
re-run, or ignore if the student is not enrolled.

**"Login failed" / authentication error**
- Make sure you are using your full BUA email as the sender
- If your account has MFA enabled, use an App Password instead of your
  regular password (generate one from your Microsoft account security settings)

**Student missing from report (no email)**
Their ID is not in `all.csv`. Add the row manually or export a fresh registry,
then re-run `prepare_students.py`.

**Wrong sections selected**
Re-run `prepare_students.py` and choose the correct sections — it overwrites
`students.xlsx` each time.
