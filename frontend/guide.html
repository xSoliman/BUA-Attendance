How to Use the System

Follow these steps to set up and run attendance for your course.

Phase 1 — Setup (one time per course)

1

Generate your attendance sheet

Go to the Tools page and open the Attendance Sheet tab. Add your students (ID, Name, Section) and give the course a name. You can add multiple courses — each becomes a separate tab in the downloaded file.

Download the .xlsx file when done.

Open Tools →
2

Import the sheet into Google Sheets

Open Google Sheets, create a new spreadsheet, then go to File → Import and upload the downloaded file.

Each course tab will appear as a separate sheet inside the spreadsheet.
3

Share the sheet with the service account

The system needs editor access to write attendance. Go to the Config page to get the service account email, then share your Google Sheet with that email as an Editor.

Get service account email →
4

Configure the system with your sheet

On the Config page, paste your Google Sheet URL (or just the spreadsheet ID). The system will validate access and save it for scanning sessions.

Open Config →
5

Generate QR codes for your students

Go to the Tools page and open the QR Codes tab. Enter the same student list (or paste from Excel). Optionally fill in College and Level for organized folder structure. Download the .zip file — it contains one QR image per student.

Open Tools →
QR files are named by student ID (e.g. 20210001.png). The zip is organized as College / Level / Group / Section / ID.png.

Phase 2 — Distribute QR codes to students

6

Get QR codes distributed to students

Each student needs to receive their personal QR code. This step involves sending the QR images by email to each student.

This step requires assistance.
Please come to room AI112 or contact me directly to complete the email distribution for your sections. Bring the list of sections you want to send to.

Phase 3 — Weekly attendance scanning

7

Start a scanning session

At the start of each lab, go to the Session page. Select your course sheet and the current week column, then tap Start Session.

Open Session →
8
8

Scan student QR codes

Go to the Scanner page. Point the camera at each student's QR code. Attendance is recorded instantly in your Google Sheet. Each student can only be scanned once per session.

Open Scanner →
Students who don't have their QR can be entered manually by typing their ID.
✓

Done — attendance is saved automatically

Every scan writes a P directly to the student's row in your Google Sheet. The Total Attendance column updates automatically. No manual saving needed.

Phase 4 — Offline scanning (no internet required)

9

Scan without internet — save as JSON

If you don't have a connection to Google Sheets during the session, scan students as usual. When done, click ↓ JSON in the scanned list header. You'll be asked to name the file — use a clear name like CS101_Week3 so you can identify it later.

Open Scanner →
The JSON file stores the course and week automatically if you had them selected. Even if you didn't, you can choose them when uploading.
10

Upload the JSON to mark attendance later

When you're back online, go to the Scanner page and scroll down to Upload attendance (JSON) to mark. Upload your saved file. The course and week will be pre-filled if the file contains them — you can still change them if needed. Then click Mark Attendance from JSON — it works exactly like a normal scan submission.

Open Scanner →
Important: If the file already has a course and week, a warning will appear before you submit. Double-check the values are correct before marking.
✓

Done — attendance marked from offline session

The system sends the student IDs from the JSON file to the Google Sheet exactly like a live scan. The Total Attendance column updates automatically.
