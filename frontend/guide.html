How to Use the System

A step-by-step guide to setting up and running attendance for your course.

Phase 1 — Setup
One time per course
1

Generate your attendance sheet

Open the Tools page and go to the Attendance Sheet tab. Add your students (ID, Name, Section) and name the course. You can add multiple courses — each becomes a separate tab in the downloaded file.

Open Tools
2

Import into Google Sheets

Open Google Sheets, create a new spreadsheet, then go to File → Import and upload the downloaded .xlsx file.

Each course tab will appear as a separate sheet inside the spreadsheet.
3

Share the sheet with the service account

The system needs editor access to write attendance. Go to the Config page to get the service account email, then share your Google Sheet with that email as an Editor.

Open Config
4

Configure the system

On the Config page, paste your Google Sheet URL or spreadsheet ID. The system validates access and saves it for all future scanning sessions.

Open Config
5

Generate QR codes for your students

Go to the Tools page and open the QR Codes tab. Enter the same student list (or paste from Excel). Optionally fill in College and Level for an organized folder structure. Download the .zip — one QR image per student.

QR files are named by student ID (e.g. 20210001.png), organized as College / Level / Section / ID.png.
Open Tools
Phase 2 — Distribute
One time per course
6

Send QR codes to students

Each student needs to receive their personal QR code by email. This step requires assistance.

Contact required.
Come to room AI112 or reach out directly to arrange email distribution for your sections. Bring the list of sections you want to send to.
Phase 3 — Weekly Scanning
Every session
7

Select your course and week

Open the Scanner page. At the top, select your course and the current week column. The current week is highlighted automatically.

Open Scanner
8

Scan student QR codes

Point the camera at each student's QR code. Each scan is recorded locally in real time. Students without their QR can be entered manually by typing their ID.

The scanner stays active between scans — no need to reset anything between students.
9

Submit to Google Sheet

When the session is done, click Submit & Mark on Sheet. All scanned students are written to your Google Sheet in one batch. The Total Attendance column updates automatically.

Open Scanner
✓

Done — attendance is saved

Every submitted student gets a P written to their row in the sheet. No manual saving needed.

Phase 4 — Offline Mode
When no internet is available
A

Scan without a Google Sheet connection

If you have no internet during the session, open the Scanner page and choose Continue in offline mode on the Config page, or just start scanning. All scans are saved locally in the browser.

You can still scan, manually enter IDs, and view the scanned list — the Submit button is disabled until you're back online.
Open Scanner
B

Save the session as a JSON file

When done scanning, click ↓ JSON in the scanned list header. You'll be prompted to name the file — use something clear like CS101_Week3. The file stores the student list along with the course and week if they were selected.

Keep the file somewhere accessible — you'll upload it later to mark attendance.
C

Upload the JSON to mark attendance

When you're back online, open the Scanner page and switch to the Upload JSON tab. Upload your saved file. The course and week are pre-filled from the file — review them, adjust if needed, then click Mark Attendance from JSON.

Open Scanner
✓

Done — offline session marked

The system submits the student IDs from the file exactly like a live scan. The Total Attendance column updates automatically.
