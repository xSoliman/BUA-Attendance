═══════════════════════════════════════════════════════════════════
WHEN USER SELECTS A PAST WEEK (e.g., Week 3):
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│                      ⚠️ WARNING DIALOG                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ⚠️ WARNING: You selected "Week 3" which is a PAST WEEK.       │
│                                                                  │
│  Current week is: Week 5                                        │
│                                                                  │
│  If you continue:                                               │
│  • You will OVERWRITE any existing attendance data for          │
│    this week                                                    │
│  • Students already marked as present may be changed            │
│                                                                  │
│  Are you sure you want to continue?                             │
│                                                                  │
│                  [ Cancel ]    [ OK ]                           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘


IF USER CLICKS "OK":
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  🟡 Toast Notification (appears for 3 seconds)                  │
│  ⚠️ Past week selected: Week 3                                  │
└─────────────────────────────────────────────────────────────────┘

→ User can now scan QR codes for Week 3
→ Any existing attendance for Week 3 will be overwritten


IF USER CLICKS "CANCEL":
═══════════════════════════════════════════════════════════════════

→ Week selection is cleared
→ Dropdown shows "Select a week" again
→ No changes made
→ User must select a different week


═══════════════════════════════════════════════════════════════════
COLOR LEGEND:
═══════════════════════════════════════════════════════════════════

🔴 RED (#dc2626)     - Past weeks (already happened)
🔵 BLUE (#2563eb)    - Current week (recommended)
⚫ BLACK (default)   - Future weeks (not yet happened)
